## 🚀 Proyectos Principales que realice en la carrera:

### 🌐 Sistema Web & Agendamiento de Citas para un cosultorio (Estadias Profecionales)
* **Descripción:** Sistema integral para la gestión y agendamiento automatizado de citas de un consultorio de psicología.
* **Características:** Integración con **Google Calendar API**, notificaciones multicanal (correo y mensajes de confirmación) y reportes en PDF y Excel.
* **Tecnologías:** Python, Django, MySQL, REST APIs, Render.

### 🛒 Punto de Venta (POS) — Refaccionaria Chayo (Estancias Profecionales)
* **Descripción:** Sistema de administración comercial orientado al control de inventario de autopartes y registro transaccional de ventas en mostrador.
* **Tecnologías:** Python, SQL, arquitectura de bases de datos relacionales.

* **Descripción:** Entorno interactivo inmersivo conectado a un torso físico sensorizado para entrenamiento médico en Reanimación Cardiopulmonar.
* **Tecnologías:** Godot Engine, Blender, Firebase, Visores VR.
